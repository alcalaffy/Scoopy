# Scoopy API 🐶

Scoopy is a backend platform built with ASP.NET Core that connects pet owners with on-demand pet waste cleaning services.

The project focuses on scalable backend architecture, clean code practices, and modern cloud-ready development using .NET 9.

---

# 🚀 Technologies

- ASP.NET Core 9
- C#
- MySQL
- Entity Framework Core
- Docker
- Redis
- JWT Authentication
- Clean Architecture
- REST API
- Swagger

---

# 🧠 Architecture

This project follows Clean Architecture principles to keep the application maintainable, scalable, and testable.

## Layers

- Domain
- Application
- Infrastructure
- API

---

# 📦 Features

- User authentication with JWT
- Pet owner management
- Cleaner management
- Booking services
- Role-based authorization
- AI-ready architecture
- PostgreSQL persistence
- Global exception handling

# ⚙️ Getting Started

## Clone repository

```bash
git clone https://github.com/alcalaffy/Scoopy
```

## Run migrations

```bash
dotnet ef database update
```

## Run application

```bash
dotnet run
```
